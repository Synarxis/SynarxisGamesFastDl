# Synarxis Games - FastDL Server Assets

This repository holds the production-built files and assets served to clients connecting to the Plutonium T6 Zombie servers.

## Repository Overview

- **`t6/mods/SynarxisGames/`**: Directory containing production-ready compiled `mod.ff`, `mod.iwd`, and associated assets.
- **`t6/zm/`**: Standalone Zombie scripts (like the chat-based banking module).

## Latest Changes, Fixes, and Implementations

### 1. Updated Compiled Mod Assets
- Updated production `mod.ff` and `mod.iwd` fastfiles.

### 2. Chat-Based Banking System
- Added `bank.gsc` and `bank_mod_main.gsc` supporting players' chat command bank interactions (`.w`, `.d`, `.b` for withdraw, deposit, and balance).
